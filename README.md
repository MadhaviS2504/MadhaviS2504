### 2️⃣ Medical Assistant — Grounded RAG Over 4,114-Page Medical Reference
**Repository:** [Natural-Language-Processing-with-Generative-AI-RAG-Project](https://github.com/MadhaviS2504/Natural-Language-Processing-with-Generative-AI-RAG-Project)

A source-grounded medical assistant built for evidence-based healthcare Q&A, with safety-focused generation aimed at reducing hallucinations.

**Highlights**
- Processed 4,114-page medical reference using PyMuPDF and LangChain
- Built 8,492 retrieval-ready chunks with token-aware chunking
- Generated embeddings using thenlper/gte-large and stored in ChromaDB
- Integrated Mistral-7B through llama.cpp with context-constrained generation
- Built LLM-as-a-Judge evaluation pipeline with groundedness and relevance validation

**Stack:** Python, LangChain, PyMuPDF, ChromaDB, Sentence Transformers, Mistral-7B, llama.cpp, Hugging Face
